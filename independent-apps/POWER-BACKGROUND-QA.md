# 宿舍电量 0.1.5 开机单次查询验收

## 功能

- 「开机自动查询」默认关闭。切换开关保存选择，普通启动应用不排查询。旧版周期任务和补查任务在升级后清理。
- 开关开启且已绑定宿舍时，系统开机或本应用覆盖更新触发一个带联网约束的单次 WorkManager 任务。任务检查绑定版本，执行查询并加密保存结果，随后结束。系统负责进程回收。
- 设置页提供厂商自启动入口和最近执行记录。各厂商的自启动设置需由用户确认。任务受系统和厂商的调度限制。
- 原包名、测试签名和加密快照格式沿用。开机查询失败时保留上次成功数据和历史。

## 验证结果

- 电量核心 79 项、应用 57 项本地测试通过。Android 16 / API 36 模拟器上 6 项仪器测试通过。
- 设备测试验证了开机及覆盖更新处理入口、旧任务清理、单次任务去重、开关关闭和未绑定时取消，以及夹具查询后重新读取加密历史。设置页测试确认开关默认关闭并显示厂商自启动入口和执行记录。
- 真机重启、厂商广播投递及真机能耗仍待实测。模拟器调用广播处理入口，并使用拦截响应代替真实电费服务。
- Release R8、lintVital、APK 签名和 zipalign 验证通过。包名 `cn.edu.gdust.suiren.power`，版本 `0.1.5`，versionCode `6`。
