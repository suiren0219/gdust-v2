# 学习助手 0.1.4 作业入口与真实列表回放

## 核对证据

针对“课程可以获取，作业不能获取”的反馈，在本机离线读取已有 HAR。未将 Cookie、账号、签名参数、真实课程正文或原 HAR 纳入仓库，也未使用样本凭据向服务发请求。

历史成功样本的作业请求为 HTTPS GET `mooc1.chaoxing.com/mooc2/work/list`，参数名是 `courseId/classId/cpi/ut/t/stuenc/enc`；课程页隐藏域和请求中的对应值逐项相同。真实 Referer 是完整的当前 `mooc2-ans/mycourse/stu` 页面 URL，而此前代码仅发送不带参数的固定课程页。

课程页菜单同时声明了作业列表地址。此前仅依据 moocDomain 拼接固定路径，未采用具体课程声明的菜单入口。

## 确认并修复的问题

1. `ChxWorkTabs` 保留当前课程落地地址及课程页面实际声明的作业入口。作业请求使用该入口及完整 Referer；旧调用未提供入口时保留兼容路径。
2. 接受已知 `/mooc2/work/list`、带 `/mooc-ans` 前缀与 `.html` 列表变体；不放行未知主机或任意路径。
3. 页面已有查询参数必须与隐藏域/所选课程一致，重复或冲突时拒绝，不重复追加签名参数。
4. 真实列表中作业条目嵌有“查看统计”的 `stat2-ans.chaoxing.com/study-knowledge/ans` 链接。旧解析器将其与作业详情地址一起校验，导致整门课失败。现在仅在存在主作业入口时忽略这一精确统计路径，从不请求统计站点；陌生、伪装或含作业详情身份的地址仍拒绝。
5. 学习助手升为 0.1.4 / versionCode 5，包名和升级签名保持兼容。

## 离线回放

在被忽略的 build 目录编写临时测试，加载同一份本机 HAR，分别检查最终请求的主机/路径、参数名、每个参数值及完整 Referer 均与记录一致，然后解析实际作业列表响应。

首次回放确认请求构造匹配，但因统计链接误判而解析失败；修复后同一回放通过，产生有合法作业 ID 与标题的结果。此测试只在本机运行，不入库、不联网、不输出参数值。

公开合成回归覆盖实际菜单入口、完整课程 Referer、参数不重复、冲突参数拒绝、不可信/冲突菜单拒绝、跨课程 Referer 拒绝、统计链接与作业详情区分。
