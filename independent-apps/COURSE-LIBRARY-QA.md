# 学习助手 0.1.11 课程分类：手动文件夹 + 校历自动学期

## 最终行为

- 两种来源交叉辅助：一是用户把课程归入自建文件夹（手动），二是按课程的「加入时间」匹配从主应用导入的校历、自动判断学期。手动归类永远优先，切换/刷新课程都不会覆盖它。
- 加入时间只认学习通课程卡片上明确标注的「加入时间：/ 选课时间：」日期；开课时间和首次发现时间都不能冒充加入时间。学习通 55 门课程样本中均未提供该字段，因此列表如实显示「待确认 · 学习通未提供加入时间」。
- 课程卡状态四类文案：`手动 · 文件夹 · 学期`（有绑定学期的文件夹）、`手动 · 文件夹`、`自动 · 学期 · 加入日期 YYYY-MM-DD`、`待确认 · <原因>`（未提供加入时间 / 尚未导入校历 / 加入日期未匹配校历）。
- 校历导入只读主应用备份 JSON 的 `term_start`、`term_weeks`、`calendar`（含 String 形式的嵌套 JSON）三类字段，备份中的账号、绑定等信息不解析、不转存；文件上限 4 MB，非主应用导出文件给出可读提示。
- 分类范围（全部 / 文件夹 / 学期 / 待确认）只收窄课程列表与本轮作业读取的目标；范围外的旧结果保留、不计为失败；受阻恢复与待补读不受范围限制。
- 删除文件夹只清除手动归属并回落到「全部课程」，按校历自动判断的结果不受影响。
- 分类数据独立持久化在快照的 `library` 字段；旧快照缺该字段时按空分类读取，不丢课程与作业。
- 学习通通知监听暂未接入：通知不携带课程身份，无法可靠判断是哪门课被加入，留作后续版本。
