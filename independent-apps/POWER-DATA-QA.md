## 修复范围

- 旧版 codec 的任意一个坏统计、样本、时区或作息字段可能让整份快照无法加载。现在按条目和可选配置隔离，仍严格验证绑定身份。
- 绑定 key 不匹配时拒绝整个主快照并尝试备份，不静默丢弃全部历史后写回空监控。
- 主快照与 `snapshot_backup_v1` 在原加密偏好文件中同步提交；保留同宿舍上次可读快照，换绑或解绑不会留下旧宿舍备份。
- 主快照损坏、缺失或条目解密失败时尝试可读备份并提示恢复；两份均不可读时保留原条目并拒绝写入默认状态。
- 本机读取失败使用独立 localError：首页、历史、设置都显示读取故障，不误显示未绑定。重试成功清除此状态。
- 包名、签名、master key alias、原 snapshot 键与快照 version 1 均保持兼容。
