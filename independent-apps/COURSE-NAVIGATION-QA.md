# 学习助手 0.1.3 课程正文读取修复与诊断

## 背景与已确认事实

用户在 0.1.2 中仍看到多门课程报告 courseid 缺失，并确认能打开课程网页，但仍拿不到作业。该反馈不能单独证明超星服务器故障，也不能证明仅靠本次补丁即可恢复全部课程。

仅在本机读取已有 HAR 的结构与请求类型，未输出 Cookie、账号、签名参数或真实页面正文。历史样本中 mycourse/stu 正文包含 courseid、clazzid、cpi、enc、workEnc、t 等字段，对应正常课程/作业请求使用桌面浏览器 User-Agent。此前原生作业请求使用 Android User-Agent，与已记录的桌面 HTML 协议不一致；此差异可能导致不同页面路由，尚未回放用户本次失败请求验证。

## 修改

- 作业请求链（课程入口、正文、作业列表与详情）统一使用桌面浏览器类型的 User-Agent，符合已有桌面 HTML 协议。登录和 Cookie 按精确 URL 读取的隔离机制不变。
- 除 HTTP 重定向外，支持 200 HTML 壳中的独立静态 location 赋值/replace/assign、meta refresh、单个已知课程正文 iframe/frame 入口。
- 不执行脚本，不解释拼接/条件/模板表达式。导航继续限制 HTTPS、可信主机、已知课程路径、参数身份及跳转次数；重复地址在请求前拒绝。
- 只有明确缺字段才尝试课程正文导航；字段冲突、账号/课程身份不匹配不能被其他框架入口掩盖。
- 缺字段错误附带脱敏落地主机/路径与固定结构摘要（courseid/enc/workEnc 是否存在、框架数），不含 query、Cookie、账号、签名或正文。
- 失败卡增加“复制诊断”，复制应用版本与已脱敏错误文案。不会主动上传页面或诊断。
- 学习助手升至 0.1.3 / versionCode 4，安装标识及签名保持兼容。
