# 学习助手 0.1.2 作业读取兼容修复

## 用户反馈与定位

用户截图显示网页登录有效，但多数课程分别报告“课程页缺少字段 courseid”与“详情地址不可信或路径不支持”。本次未读取用户 Cookie、账号或真实页面正文，因此不能由截图证明所有课程失败都属于同一种页面变体。

源码中确认并修复的兼容缺陷：

- 课程隐藏域原先只按 id 读取；现在支持 id/name，不区分字段名大小写，兼容省略 type 的输入。脚本、样式和 template 中的伪字段不作为证据。
- 课程身份允许来自实际可信响应落地 URL；URL 和正文中所有已存在的身份参数都必须与所选课程匹配，缺失、重复或冲突仍报错。不会凭空补 enc/workEnc/t 等签名参数。
- 列表中的 work/task 相对引用按作业模块根解析，避免生成 work/work/task；仅对精确的已知列表路径应用此规则。可信主机、HTTPS、端口、路径穿越和跨课程校验保持。
- 仍不支持的详情链接会显示脱敏主机/路径，不输出 query、Cookie 或签名值。

## 使用体验

失败课程默认折叠，成功读取的作业不再被大量错误卡片挤到页面末尾。展开后保留单课重试，并增加打开课程原网页。未读课程仍明确标记未知，不算空作业。
